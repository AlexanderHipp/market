# Market

Enter a company, product, or idea → get the competitive landscape.

## Setup

```bash
npm install
```

Create `.env.local`:

```
OPENAI_API_KEY=sk-...
```

Run:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Tech

- Next.js 16
- React 19
- Tailwind CSS 4
- OpenAI (GPT-4o)
